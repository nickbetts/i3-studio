# Product UI/UX audit - 17 September 2026

## Evidence and direction

Full source inventory: 36 page files, including redirect routes. Before application edits, an opt-in Playwright sweep visited all agency, client, onboarding and public destinations with isolated fixture accounts. Authenticated routes were captured at 1440px and 390px, public pages at 390px. Completed-page headings are awaited to avoid mistaking loading skeletons for pages. The final sweep also renders onboarding using an isolated incomplete client account.

Confirmed browser defects: task detail extends above/below the viewport; the client company name expands the mobile header and causes overflow on every portal route. Source-confirmed defects: dashboard link matches every child route; September date inputs become 31 August through UTC conversion; budget and spent queries can use different periods; task dependency selection requires a raw ID; support rows are mouse-only. Verification additionally identified a CSP-blocked private upload: the SDK requires `https://vercel.com/api/blob/` in connect-src. This was corrected narrowly and the real upload regression now passes. Support attachment links now use the tenant-checked download route rather than inaccessible private Blob URLs. Search no longer resets pagination on initial mount.

Design references: [Linear's compact work navigation](https://linear.app/features) and [Attio's record-first views](https://attio.com/). Apply patterns, not copied layouts or marketing content. Keep Geist, i3 branding and the existing dark workspace; introduce a restrained mint accent with amber/red reserved for attention. No speculative analytics, fake trends or animations that imply work is still loading.

## Acceptance checks

- Existing unit/security tests and production build remain gates.
- Dedicated budget tests cover zero budget, missing allocation, exact exhaustion, overrun, seconds, date boundaries and intersecting custom periods.
- Re-run all rendered routes at desktop/mobile sizes, including long names and task detail. No page-level horizontal overflow or off-screen task dialog.
- Browser checks exercise page switching, compact creation, period navigation, budget progress and existing client/project/task workflows. Do not send real client mail or reset data.
- External private Blob upload tests depend on valid storage credentials; distinguish unavailable storage from UI failures.

## Boundaries

This is the visual/workflow audit implementation, not a claim of feature parity with ClickUp. Earlier roadmap work left notification/reminder automation, advanced workload analytics and robust recurrence/dependency enforcement incomplete. Those require separately specified behavior and tests, not cosmetic success claims. This pass makes no new claims about them.

## Final results

- `pnpm lint`, `pnpm typecheck`, and `pnpm build`: passed.
- `pnpm test`: 41 tests passed, including 12 budget/period/formatting cases.
- `UI_AUDIT=verified E2E_ENV_FILE=/tmp/i3-production.env pnpm exec playwright test --reporter=line`: all 10 tests passed, including the real private-file upload and existing approval, tenant-isolation, template, client/project setup and task-assignment workflows.
- Final desktop/mobile route sweep: no page-level overflow, no off-screen task dialog, no application-error pages.
- Verified 60% usage, a capped 100% overage bar, client-isolated reports/downloads, month navigation, task tabs, and page switching.
- Screenshots are generated under `test-results/audit-verified/` by the opt-in audit; fixture records are removed by the existing test teardown. No production database schema changes or resets.
- Existing Next.js stream-close diagnostics still appear during some navigations; they did not fail the verified workflows. The prior upload failure was specifically CSP, not these diagnostics.
